# PocketSmart AI

### AI-Powered Personal Budget & Shopping Recommendation System

PocketSmart AI is an AI-powered web application developed as part of the **Naan Mudhalvan Project**. It helps users plan their expenses and receive personalized shopping recommendations based on their **budget and preferences**.

## Features

* 🔐 User Registration & Login
* 🏠 Home Budget Planner
* 🎉 Party Budget Planner
* 💎 Jewelry Budget Planner
* 🤖 AI-Powered Recommendations
* 💰 Budget-Based Suggestions
* 🛒 Shopping Platform Links
* 📋 Recommendation History
* 📊 Personalized Budget Planning

## Objective

To develop an intelligent and user-friendly system that helps users make **smart, personalized, and budget-conscious shopping decisions** using Artificial Intelligence.

## Workflow

```text
Login
  ↓
Select Planner
  ↓
Enter Budget & Preferences
  ↓
AI Recommendation
  ↓
View Personalized Suggestions
  ↓
Save Recommendation History
```

## Project Outcome

PocketSmart AI provides users with a simple and intelligent way to manage their shopping plans while staying within their desired budget.
